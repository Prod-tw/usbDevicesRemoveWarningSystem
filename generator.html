USB 裝置移除監控 — 設定產生器

填入以下參數，產生 config.json 設定檔供下載
留空將自動帶入預設伺服器位址
顯示 / 隱藏
留空將自動帶入預設金鑰
留空則監控全部 USB 磁碟。要查序號，先執行一次 run.bat，視窗會列出目前接上的所有 USB 磁碟與序號，複製過來即可。序號大小寫不拘。
相對路徑會以 monitor.ps1 所在資料夾為基準。建議用 .wav（由 .NET 內建播放器處理，最穩定）；.mp3 / .wma 改走 Windows Media Player，需系統已安裝。
⚠️ 瀏覽器基於安全機制，無法直接寫入你電腦上的檔案，也無法啟動程式。按下按鈕後會下載一份 config.json，把它放進 monitor.ps1 所在的資料夾即可 —— 腳本本身不需要重新產生，日後要換伺服器或改音效，直接編輯 config.json 就好。
下載後的執行步驟：
1. 把下載的 config.json 放進專案資料夾（與 monitor.ps1、Modules\BurntToast\ 同一層），覆蓋既有的那份
2. 若使用自訂音效，把音效檔放到上面填寫的路徑
3. 以系統管理員身分執行 run.bat
4. 或手動執行：開啟系統管理員 PowerShell，cd 到該資料夾後執行 .\monitor.ps1；若被執行原則擋下，先跑一次 Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
